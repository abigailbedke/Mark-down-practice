### What is Mark Down?
Mark down is digital tool that is used to convert and organize plain text. Due to its simplistic Nature, Mark down can be used by anyone.This has lead markdown to become Infrastructural, and has influenced people around the would on how they go about creating digital spaces. 

__List of markdown capabilities:__
1. Headers
2. Emphasis
3. Lists
4. Links
5. Images
6. Code and Syntax Highlighting
7. Block Quotes
8. Horizontal Rule🙃🙃🙃
9. YouTube Videos
