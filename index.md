### What is Mark Down?
Mark down is a digital tool that is used to organise and format plain text.Created by John Gruber in 2004, it was designed to be a lightweight mark up language. Instead of using HTML tags, writers can use simple symbols to create headings, lists, links, and emphasis. Due to its simplistic nature, Mark down can be used by anyone to create without needing prior coding knowlege. Mark Down is great for simplistic linear formatting, such as blogs, notes, and basic webpages. However, this simplicity creates some limitations.

### What are Markdown's Limitations?
Markdown excels for basic types of writing, but is not designed for everything. It prioritises ease over variety, which makes adding footnotes, tables, and graphs alot trickier. Markdown has a particular vision of how a document must look like. Markdown presumes a document consists mostly of text that has to be divided into simple parts. This is probably one of the reasons it is so convenient to use but at the same time it can become annoying for the person who is willing to create a more complicated piece.The constraints of Markdown are the consequence of its initial design aiming at making it straightforward rather than capable of dealing with all possible types of documents.

### How has Markdown Changed?
Mark down has grown beyond what is was originally created to do. Gruber designed Markdown for web writers who wanted an easier way to create HTML but Markdown is now used for many other things, including notes, documentation, academic writing and AI‑generated text. Once a format becomes widely used other tools and systems begin to depend on Markdown, which can make it infrastructural. Markdown started as a tool, for web writing but the widespread use of Markdown has made it an important part of how people create and share digital information.
